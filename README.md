# SriSri-Portfolio
## “A Living Invitation”

A production-ready static, cinematic family-introduction site built from scratch with plain HTML/CSS/JS.

### What changed in V4
- Chapter-based cinematic narrative with live chapter indicator and scroll progress
- Editorial typography using Playfair Display, Manrope and DM Mono
- Decorative India → Germany route animation with no external map dependency
- Parallax portraits and reduced-motion fallback
- Roots / horoscope metadata presentation
- Family mosaic and cinematic quote chapter
- Invitation-envelope final CTA with accessible `<dialog>`
- Responsive mobile layout
- No build step, framework, backend, analytics or external API required
- Five supplied portrait assets reused across the story
- Personal-data privacy guidance included

### Files
- `index.html`
- `styles.css`
- `script.js`
- `assets/*.jpg`

### Deploy
Upload the folder to Vercel, Netlify, Cloudflare Pages, GitHub Pages, or any static host.

### Before publishing
1. Replace `REPLACE-WITH-FAMILY-EMAIL@example.com` in `index.html` with the family-approved contact method.
2. Review every personal detail for accuracy.
3. Because the page contains personal information, prefer private sharing, password protection, or an unlisted/private deployment if appropriate.
4. Add your own favicon/OG image if desired.
5. If you don't want Google Fonts, self-host the font files and update the CSS.

### Accessibility
The page includes semantic sections, dialog controls, alt text, keyboard-friendly buttons/links, and `prefers-reduced-motion` behavior.

### Notes
The route map is an artistic illustration, not a geographic navigation map. The Makara/Sravana display is presented as family-provided profile information, not as an astronomical calculation.
